# Cursos introdutórios de tecnologia com apostilas

- Adicionar Git e GitHub, APIs REST e JSON, e Python para automação ao catálogo.
- Cada curso tem duas aulas introdutórias e uma apostila PDF original vinculada à primeira aula pelo mecanismo de anexos existente.
- A importação recebe o e-mail de um professor existente. Ela cria os três cursos publicados em uma transação, sem criar contas ou alterar cursos existentes.
- Repetir a importação não duplica cursos. O catálogo e o download usam as mesmas regras de acesso dos demais cursos.
